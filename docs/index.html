3D 小虎鲸.

一只透明置顶的 3D 虎鲸，常驻在你的桌面上。它会跟着鼠标游，头一直朝着你的箭头； 你不动它，它就自己溜达、翻跟头、打个盹；你把手放它头上蹭两下，它会眯起眼睛冒一屏爱心。

安装
$ dsh-3d-whale-pet
国内下载慢的话，改装这条：
https://gitee.com/in-search-of-ink/dsh-3d-whale-pet/raw/master/dsh-3d-whale-pet.tgz

把上面这条链接粘进 DSH 插件面板的安装框即可。 装好之后在插件面板点「启动」——第一次会提示下载桌宠本体（约 180 MB），之后离线可用。

它会做什么

🐭

跟着鼠标游

朝你的箭头游过来，停在手边一掌远；靠近时会减速，不是硬停在某个点。

👀

头一直朝你

光标越过 90° 就真的转过头，不会倒着游。手贴到脸上时它会正对屏幕看你。

🧭

自己溜达

鼠标静下来十秒，它就去窗边逛一圈；逛累了翻个跟头，或者闭眼睡三十秒。

💗

被摸会开心

在脑袋上蹭三次，它会眯成笑眼、抖抖身子、冒一屏爱心，然后说句话。

🐟

大鱼吃小鱼

菜单里开一局，点屏幕任意位置投鱼，它会加速追着吃。游戏期间换一套台词。

💬

台词自己挑

内置台词逐条开关（只能关不能删），也能加自己的——增删改都行，每条还能单独关。攒几批按心情切换，升级不丢。

💭

知道你在动脑

DSH 深度求索时头顶冒省略号，想出结果时闪灯泡、扇鳍、轻轻上浮，还配一声「叮」。

🎨

换皮肤 / 换体型

五种配色、四档体型，还能自己调深浅两色。选过的会记住，下次启动还是它。

装在哪 / 换盘

桌宠本体约 180 MB，默认在 %APPDATA%\whale-pet-app\runtime（C 盘）。想换到 D 盘：关闭桌宠 → 插件面板里点「安装位置」后面的「更改」 → 填一个空目录 → 保存，会自动搬过去并记住。输入框留空保存即恢复默认。
