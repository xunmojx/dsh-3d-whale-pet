# 🐋 3D 小虎鲸

3D 小虎鲸桌宠：可以跟着鼠标，也可以自己溜达、翻身、打盹，还可以简单互动。把鼠标箭头放它头上蹭三下可以摸摸它。放歌时会跟着节拍点头（本地音频或任何软件的声音都行）。它说的话可以自己挑——内置台词能逐条开关，也能加自己的，都存在本地、升级不丢。

> **想连同本地数据一起删掉？** 右键小虎鲸 → 📖 帮助 → 拉到最底下，点「删除本地数据」。
> 只点插件的「卸载」是不会删这些的——设置会留着，重装还是原来的样子；点了「删除本地数据」之后插件就启动不了了，重装也得重新下载、不再记得原来的设置。

## 安装

插件面板里粘贴下面这条**直连链接**（推荐，国内也快，而且一定是最新版）：

```
https://gitee.com/in-search-of-ink/dsh-3d-whale-pet/raw/master/dsh-3d-whale-pet.tgz
```

也可以用包名从 npm 装：

```
dsh-3d-whale-pet
```

> **为什么推荐直连链接**：国内 npm 镜像（npmmirror）同步有延迟，有时会滞后十几个版本；从包里搜名字装，可能装到几天前的旧版，看起来就像「更新没生效」。直连 tgz 不经过镜像，拿到的一定是最新打包好的版本。
>
> 点桌宠菜单里的「去更新」时，这条链接会自动复制到剪贴板，直接粘进插件面板即可。

## 如何更新

仓库里出了新版本，桌宠启动后（或每次右键打开菜单时）会去查一次。查到就在菜单**最上面**多一行蓝底提示：

```
⬆️ 新版本 x.x.x    去更新
```

点它会**把 DSH 窗口切到前台**，同时把**直连安装链接复制到剪贴板**，并冒一句「已复制直连链接，去「插件」页粘贴安装」。然后：

1. 在插件面板点「**卸载**」——**不会删**你的设置，也不会删 180MB 的桌宠本体
2. 把刚复制的链接粘进安装框，装一次
3. 点「启动」

就这么三步，**链接永远是同一条**，不用记也不用换。装完设置还是原来的样子。

> 想彻底清干净（连设置和 180MB 一起删）见下面「卸载与删除本地数据」。

## 怎么用（就两步）

- **左键单击它** —— 和它互动：它会说句话，左边弹出三个动作键（喂食 / 爱心 / 睡眠），下方出现派活输入框。动作键**点完不会收起**，可以连着喂、摸摸、再让它睡；输入框也是**常驻**的，回车发完可以接着打下一句（Esc 才关）。**点小虎鲸以外的地方收起面板**。
- **右键单击它** —— 打开功能菜单：**跟随鼠标、待机自动漫游**的开关都在最上面；换皮肤、跳舞强度、播放器、查余额、帮助也都在这里。

> 窗口默认是点击穿透的，只有落在鲸鱼身上才会接住鼠标——命中区按模型的真实轮廓判定（光线检测，尾鳍和胸鳍这些细条都算），不是外接的方框或椭圆；动作面板打开时只放开左侧那一条竖带（够按按钮即可），其余区域照样穿透，8 秒后自动收回。

## 它会做什么

· 跟随：朝鼠标游过来（**首次安装默认是关的**，想让它跟你在菜单里打开，之后会记住）
· 朝向：开启鼠标跟随后，头始终朝箭头，不会倒着游
· 漫游：鼠标静止 10 秒，它自己去逛
· 待机：翻个跟头，或者闭眼睡 30~60 秒
· 互动：在脑袋上蹭三次，摸摸它
· 闲聊：30~70 秒自言自语一句（内容可以自己挑，见下面「台词管理」）
· 思考提示：DSH 正在深度求索时，它头顶冒一串省略号；想出结果时闪一下小灯泡，同时眯眼、扇鳍、轻轻上浮

## 更多功能

· 大鱼吃小鱼：菜单里开一局，左键点屏幕任意位置投鱼，它会追着吃
· 换皮肤：五种预设配色（深寻蓝 / 虎鲸黑 / 草莓粉 / 薄荷绿 / 土豪金），还能自定义深浅两色
· 播放音乐：导入本地音频（**列表会记住**，下次打开还在），它跟着节拍上下点头——**快歌点得快、慢歌点得缓**，三档强度分别是「一直点 / 点几下停一下 / 偶尔点」
· 监听电脑声音：播放器里点「🎧 监听电脑声音」，网易云、QQ 音乐、浏览器在放什么它都能听见，照样跟着点头（只听不放，不会干扰你正在听的声音）
· 取名：右键菜单 → 🏷️ 给我取名（最多 12 字）。取完之后任务栏标题变成这个名字，而且它**三分之一的闲聊会以这个名字作主语**——「小鲸不会忘记这个名字」「小鲸觉得，这个名字很好听」。名字存在本地，下次启动还在
· 查余额：一键查 DeepSeek 余额，低于 ¥1 会提醒
· 台词管理：右键菜单 → 💬 台词管理。四类台词（被点击 / 待机闲聊 / 被摸头 / 游戏里）分开管：**内置的只能勾选用不用、不能删**（方便以后再加固定台词）；**自己加的可以增删改，还能单独开关**——可以攒几批，按心情开一批关一批。全部存在本地，升级插件不会覆盖
· 音效：点击、吃鱼、摸头、想出结果各有一声，音色都不同（吃鱼是上挑的「啾」，摸头是软软的「嗯~」，结果是清亮的「叮」）
· 小游戏手感：鱼平时会自己慢慢游，靠近才逃；吃掉的鱼在嘴边消失，不再是固定从左边冒出来

## 不会烦你

· 可控：跟随鼠标、待机自动漫游都能在菜单里单独开关
· 记得住：体型、这两个开关都会存到本地，重开桌宠还是你上次的样子
· 不挡事：默认点击穿透，只有身体接鼠标
· 被拖拽时暂停跟随，松手 6 秒后才恢复，方便摆位置
· 说话有节流；睡着时不讲话；**DSH 有任务在跑时一律不讲话**——摸它、点它、按动作键都只有动作和音效，一句话都不说，不打扰你
· 拖动时身体会跟着侧倾，但不会误触发「摸头」

## 体积

插件包本身只有 327 KB——源码、渲染资源都在里面，不含二进制。

桌宠本体是 Electron 应用，体积约 180 MB，不打进包里。第一次点「启动」时，面板会显示「安装依赖」按钮，点一下现场下载，装完就能用，之后离线也正常。这部分依赖默认放在 `%APPDATA%\whale-pet-app\runtime`（也就是 C 盘），**可以在插件面板里改到别的盘**，见下面「装在哪 / 怎么改位置」。它不在插件目录里——所以重装插件不用重下，卸载也不会卡。

## 装在哪 / 怎么改位置

桌宠本体（Electron，约 180 MB）默认装在：

```
%APPDATA%\whale-pet-app\runtime
```

也就是 `C:\Users\你的用户名\AppData\Roaming\whale-pet-app\runtime`。不在插件目录里，所以**重装插件不用重下，卸载也不会卡**。

**想挪到别的盘（比如 C 盘紧张）：**

1. 打开 DSH 侧边栏的插件面板，找到小虎鲸那一栏
2. 面板里有一行小字 `安装位置：C:\...\whale-pet-app\runtime`，点它后面的**「更改」**
3. 填一个**空目录**（例如 `D:\whale-pet`），点「保存」
4. 它会把整个运行时**复制**到新位置、修好里面所有链接、再把插件接过去，并记住这个位置——之后显示 `安装位置：D:\whale-pet`

**几条要注意的：**

- **桌宠运行中不能改**（文件被占用），先关掉桌宠再改；这时「更改」两个字也不会显示
- 目标目录**必须是空的或不存在**，防止误覆盖
- 想改回默认：把输入框**留空**再保存
- 换盘不影响任何设置，皮肤、体型、台词都还在
- **同一个盘内改位置是瞬间的**：直接改名 + 修正里面的链接，不复制、不下载
- **跨盘（比如 C → D）需要在新位置重新装一次依赖**：pnpm 的包不能跨盘硬链接，只能重建；走的是本地缓存，不重新下载整个包，但会花一点时间

> 手工也行：在 `%APPDATA%\whale-pet-app\location.json` 里写 `{"runtimeDir": "D:\\whale-pet"}`，然后把原 `runtime` 整个剪到那个目录、重开 DSH。用面板更省事。

## 有新版本会提醒

桌宠启动后几秒会悄悄去仓库看一眼版本号（拉一份 `version.json`，几 KB，网络不通就静默跳过，不打扰你）。

发现仓库里比你装的版本新，**右键菜单最上面会多出一行蓝色提示**：

```
⬆️ 新版本 x.y.z    去更新
```

点它会把你送回 DSH 窗口，**同时把直连安装链接复制到剪贴板**，并冒一句「已复制直连链接，去「插件」页粘贴安装」；万一切不过去，会把项目主页打开。更新方式就两步：**插件面板里卸载 → 粘贴链接重装**。链接永远是同一条，不用换。

## 卸载与「删除本地数据」

这两个是分开的：

| 操作 | 插件目录 | 你的设置 | 桌宠本体（180MB） |
| --- | --- | --- | --- |
| 卸载插件 | 删除 | **保留** | **保留** |
| 删除本地数据 | 不动 | 删除 | 删除 |

**卸载**只清插件本身。体型、皮肤、跳舞强度、跟随和漫游开关都在
`%APPDATA%\whale-pet-app\whale-pet-config.json`，重装之后还是上次的样子。

**删除本地数据**是彻底清理：右键菜单 → 帮助 → 拉到最底下，点那个红色的「删除本地数据」
（要点两次确认）。删完之后插件还装着但启动不了——因为桌宠本体也没了；重装得重新下载，
而且不再记得原来的设置。

> 只想省磁盘、还打算重装的人别点它。它删的就是那份 180MB，重装还得下回来。

## 已知限制

- **Electron 不走插件包**：首次使用需要联网下载约 180 MB，网络慢时请耐心等待。
- **派活是要花钱的**：在鲸鱼嘴里那个输入框打字，会作为一条真实消息发进你 **DSH 当前打开的会话**，调模型、消耗 token、计入上下文。想聊天建议回 DSH 里打——气泡最宽 252px，长回复读着累。
- **但它自己说话不要钱**：30~70 秒的闲聊、被摸时的「再摸摸嘛」、点击时的「摸鱼中，别打扰我」，全是本地写死的台词，不消耗 token。
- **纸片模型的转身**：它是一张有厚度的「剪纸」，绕竖轴转到 90° 会变成一条窄边——这是几何决定的，所有转向逻辑都绕开了这个角度。
