📖 帮助

🖱️ 基本操作

左键拖动 移动桌宠窗口

左键单击 弹出派活输入框 + 互动泡泡（点小虎鲸以外的地方收起）

右键单击 打开菜单（跟随鼠标 / 待机自动漫游 / 换皮肤 / 跳舞强度 / 播放器 / 台词管理 / 余额 / 帮助）。改设置不会自动关菜单，可以连着调几项

菜单会贴在虎鲸旁边弹出，点旁边的空白处或按 Esc 就收起；右边放不下时会自动翻到左边。

右键拖动 旋转视角

安装 / 重装：插件面板里粘贴直连链接 https://gitee.com/in-search-of-ink/dsh-3d-whale-pet/raw/master/dsh-3d-whale-pet.tgz 最稳（不经过国内镜像，一定是最新版）；也可以直接写包名 dsh-3d-whale-pet，但镜像同步有延迟时可能装到旧版。

装在哪：第一次点「启动」会下载桌宠本体（约 180 MB），默认放在 C 盘
%APPDATA%\whale-pet-app\runtime。它不在插件目录里，所以重装插件不用重下、卸载也不会卡。

怎么改到别的盘：

1. 先关闭桌宠（运行中文件被占用，改不了）

2. 打开 DSH 侧边栏的插件面板，找到「安装位置：…」那一行，点后面的小字「更改」

3. 填一个空目录（例如 D:\whale-pet），点「保存」

4. 它会自动搬移并记住，成功后显示 ✓ 已改到 D:\whale-pet

想改回默认：输入框留空再保存。设置（皮肤、体型、台词）不受影响。同一个盘内换位置是瞬间完成的（改名 + 修链接）；跨盘（比如 C 到 D）会在新位置重建依赖，走本地缓存、不重新下载整包。

如果仓库里出了比你装的新的版本，菜单最上面会多出一行蓝色提示（⬆️ 新版本 x.y.z）。点它会把你送回 DSH 窗口，同时把直连安装链接复制到剪贴板——直接粘进插件面板就行，这条链接不经过国内镜像，一定是最新版（切不过去时会把项目主页打开）。检查是启动后悄悄做的，网络不通就跳过，不会打扰你。

🐭 跟随鼠标

右键菜单 → 🐭 跟随鼠标 打开或关闭。首次安装默认是关的，打开之后会记住，下次还是开的。

打开时：它会朝你的鼠标游过来，停在手边约一掌的距离，脑袋一直朝着箭头——光标跑到它正上方，它会把头仰起来指过去。

关掉后：不再追你，原地待着（是否自己游，看下面那个开关）。

🧭 待机自动漫游

右键菜单 → 🧭 待机自动漫游 打开或关闭。

打开时：鼠标静止 10 秒，它就开始在屏幕上自己逛——随机挑个点游过去，到了歇两三秒，再换下一个。游动时脑袋朝着游的方向。

关掉后：没人理它就停在原地，只转头看你。

两个开关互不干扰：跟随关掉后它不会来追你，但只要漫游还开着，它照样会自己溜达。

这两个开关的状态也会记住，重开桌宠不会回到默认。

😴 待机小动作

很久没人理（约 2.5 分钟），它会随机做一件事，两件事不会同时出现：

🌀 翻个跟头：头向上仰，绕横轴翻一整圈，中途会露出肚皮朝上的样子。

💤 睡一觉：闭眼待 30~60 秒，头顶飘出流动渐变的 zzz。睡着时不动也不说话。点它一下、或者蹭蹭它都能提前叫醒，醒来会说一句「醒啦」。

🐟 互动

点击鲸鱼后，窗口左侧会出现三个互动泡泡：

🐟 喂食 → 小鱼游入鲸鱼嘴里

💗 爱心 → 冒出爱心，鲸鱼欢快扑腾

💤 睡眠 → 鲸鱼闭眼入睡（再点一次或点击鲸鱼唤醒）

泡泡点完不会收——可以连着喂、摸摸、再让它睡。收起方式：点小虎鲸以外的地方；或者不动它们 8 秒会自动收。

下面的派活输入框是常驻的：回车发完内容就清空、框留着，可以接着派下一个活；只有按 Esc 才关。

💗 摸摸它

把鼠标放到它脑袋上，快速左右来回蹭三次以上——它会眯起眼睛（压成一条上扬的弧）、轻轻抖一下身子、冒出粉色爱心，然后说一句话。

💬 闲聊

没人说话时，它每隔 30~70 秒会自己冒一句：夸你、提醒你歇会儿、说自己打了个哈欠之类。

正在说别的内容（比如流式回复、报错）时不会插嘴；睡着时也不说话。

DSH 有任务在跑时不讲话：深度求索期间摸它、点它、按动作键，都只有动作和音效（摸头的爱心、点击的小跳、动作键的效果都照旧），不会冒出任何台词气泡。任务跑完就恢复正常。

这些闲聊内容可以自己挑，见下面「💬 台词管理」。

🧭 调整初始角度

右键菜单 → 🧭 调整初始角度 会在桌宠旁边开一个小窗口，不挡它本体。

三根滑杆：左右偏转（头朝左还是朝右偏多少）、上下俯仰（头抬高/压低）、侧倾（绕身体长轴翻，角度大了会露肚皮）。拖动即时生效，松手自动保存，下次启动还是这个角度。

侧倾超过约 60° 会开始变薄片——模型是一张有厚度的剪纸，翻到 90° 就是一条边。

💬 台词管理

右键菜单 → 💬 台词管理 打开一个设置窗口，把台词按四类分开：被点击时 / 待机闲聊 / 被摸头时 / 游戏里。

内置台词（灰底「内置」标签）只能勾选「用不用」，不能删——取消勾选那句就再也不说了，勾回来立刻恢复。

我的台词（绿色「我的」标签）可以「改」「删」，下面输入框还能加新的。每条前面也有勾选框，关掉只是暂时不说、内容留着——可以攒几批，按心情开一批关一批。

所有内容都存在本地配置文件里，升级插件不会覆盖。

💭 它也在看你干活

DSH 开始深度求索时，它头顶会冒一串省略号（1 个点到 6 个点循环）。想出结果时，灯泡闪一下、眯起眼睛、扇两下鳍、轻轻往上浮一下——同时有一声清亮的「叮」。

思考期间它不会打盹、不会翻跟头、也不会闲聊插嘴；要是你正好在它睡觉时开始思考，它会被立刻叫醒。

如果桌宠是在思考途中才启动的，它也能补上状态——先冒省略号，想完照样闪灯泡。

🔊 音效

都是现场合成的，不占体积：点击是海豚式的啾、吃鱼是上挑的「啾」加一声咕嘟、摸头是软软的「嗯~」、想出结果是清亮的「叮」。四种音色区分得很开。

🏷️ 给我取名

右键菜单 → 🏷️ 给我取名 弹出一个输入框，最多 12 个字。

取了名字之后会有什么不一样：

· 任务栏标题变成这个名字（原来叫「虎鲸桌宠」）。

· 它大概三分之一的闲聊会以这个名字作主语，比如「小鲸不会忘记这个名字」「小鲸觉得，这个名字很好听」「小鲸想知道，你今天有没有好好喝水」。这是取名唯一真正的作用——不然名字只是挂在任务栏上，跟它本身没什么关系。

· 剩下三分之二的闲聊还是原来那 14 句，不念名字。混着说才自然，句句都带名字反而像在播报。

名字存在本地配置里，下次启动还在。想改就再点一次；把输入框清空保存，标题会回到「虎鲸桌宠」，闲聊也回到不带名字的状态。

📏 体型大小

右键菜单 → 体型大小：小 / 中 / 大 / 特大四档。窗口和模型会一起缩放，不会出现「模型变大被窗口切掉」，换了档位它会重新算漫游点位。

选过的档位会记住，下次启动还是这个大小。

🎨 换皮肤

右键菜单 → 换皮肤：深寻蓝 / 虎鲸黑 / 草莓粉 / 薄荷绿 / 土豪金，或选「自定义配色」用取色器自由搭配身体与肚皮颜色。

🎚 跳舞强度

右键菜单 → 跳舞强度：关闭 / 低 / 中 / 高，控制播放音乐时鲸鱼随节奏跳舞的活跃度。

🎵 播放器

右键菜单 → 播放器：导入本地音频，虎鲸会随节拍打点、偶尔转圈、头顶冒音符。

列表会记住：导入过的音频存在本地，下次打开播放器还在（文件别挪位置或改名，挪了就打不开）。

🎧 监听电脑声音：点一下开始，再点一下停。它会抓取系统正在播放的声音——网易云、QQ 音乐、网页里的歌都行，照样跟着点头。只听不放，不会多出任何声音。

点头怎么跟的：播放器会估算当前这首歌的拍速，快歌点得快、慢歌点得缓。播放器下面那行会显示 BPM 和拍间隔，是只读的，方便你看它估得准不准。

跳舞强度分三档：高 每一拍都点；中 点 3~5 下停 3~5 拍；低 点 3~5 下停 6~11 拍。跳舞期间它不会犯困睡着。

💰 查询余额

右键菜单 → 查询余额：虎鲸会读取 ~/.dsh/.credentials.yaml 里的 DeepSeek API Key，向官方接口查询账户余额并播报。

余额低于 ¥1 时会额外提醒充值；查询结果会显示总余额与赠金。

🪟 点击穿透

窗口默认是「穿透」的：除了鲸鱼身上那一小块，周围的透明区域都不吃鼠标，你可以直接点它下面的东西。

只有两种情况会暂时接住鼠标：光标落在鲸鱼身上（按模型的真实轮廓判定，尾鳍、胸鳍这些细条都算，不是外接的方框或椭圆）；或者左侧三个互动泡泡打开时——这时只放开左侧那一条竖带（约 92px 宽，够按按钮就行）。其余透明区域一律穿透，面板 8 秒后自动收回。

🎮 大鱼吃小鱼

右键菜单 → 🎮 大鱼吃小鱼：勾上就开始。

开始后屏幕上会铺一层看不见的透明层，左键点屏幕任意位置就投一条小鱼下去。

小鱼会自己游，而且远远看见小虎鲸就开始逃（警戒范围挺大，越近逃得越急，但再快也逃不掉）；小虎鲸看到鱼会加速追（比平时跟手快得多），追的时候头一直朝着鱼的方向，和它盯着你的鼠标时一样。

撞上就把鱼吃掉——反应和喂食一样：小鱼游进嘴里、它欢快扑腾一下，然后说一句话。

游戏期间它换了一套台词：吃到鱼会说「好吃！」「再来一条」「嗯……鲜」这类；点它会说「别闹，我在捕猎」；蹭它会说「等我吃完嘛」。平时那 14 句闲聊在游戏里不会被调用。

右键点任意位置退出游戏。

注意：游戏期间那层全屏透明层会接管鼠标点击，桌面上的东西暂时点不到（退出就恢复）。小虎鲸自己也完全让开鼠标，点它身上也是投鱼。

💬 派活

⚠️ 派活是真的调用模型，会花钱。你在输入框里打的字，会作为一条真实消息发进 DSH 当前打开的那个会话——消耗 token，并且计入那段对话的上下文；模型的回复再流式回到气泡里显示。

也就是说，它更像「用鲸鱼当输入框发消息」，而不是和一只宠物闲聊。想聊天建议还是回 DSH 里打（气泡最宽 252px，长回复读起来很累）。

而它自己主动说的话——30~70 秒的闲聊、被摸时的「再摸摸嘛」、点击时的「摸鱼中，别打扰我」——都是本地写死的台词，一句都不消耗 token。

单击鲸鱼 → 输入一句话，虎鲸会把它派给 dsh harness 并流式回显结果。

消息会发送到 harness 当前打开的窗口（即最近在聊的那个会话），切窗口时自动跟随。需先启动 dsh；DSH 桌面版每次启动的端口都是随机的，所以地址由插件自动传递 / 发现：从侧边栏启动时由插件直接传 WHALE_PET_URL，手动 npm start 时读发现文件 %DSH_HOME%/cache/whale-pet-dsh-url.json。想显式覆盖就设 WHALE_PET_URL。

新版 dsh 需要鉴权，桌宠会自动读取 ~/.dsh/.credentials.yaml 的密钥签发会话 Cookie，无需手动配置。

🗑️ 删除本地数据

卸载插件不会删掉你在这里的东西——体型、皮肤、跳舞强度、跟随和漫游开关都存在 %APPDATA%\whale-pet-app\whale-pet-config.json，重装之后还是上次的样子。

如果你打算彻底不要它了，点下面的按钮。这会删掉配置和 180MB 的桌宠本体， 之后插件仍然装着但启动不了，重装也得重新下载、不再记得原来的设置。
